# ErgoSense – Firmware

_mainteiner: Rafael Gontijo Ferreira_

Firmware responsável pela coleta, processamento e envio de dados posturais utilizados no sistema **ErgoSense**. Este firmware integra sensores instalados em cadeiras e encostos, permitindo monitoramento contínuo da postura do usuário e envio das medições para uma base de dados para posterior análise ergonômica.
